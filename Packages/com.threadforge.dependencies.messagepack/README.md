# MessagePack dependency distribution

Pinned MessagePack 3.1.12 runtime, annotations and analyzer/source generator; Microsoft.NET.StringTools 17.11.4; System.Collections.Immutable 8.0.0. Existing binaries and importer GUIDs are preserved. Unity formatters remain in the separately installed com.github.messagepack-csharp package.

The .NET Standard 2.1 runtime uses Unity-provided base framework assemblies; no reflection/typeless resolver is selected by Threadlink persistence. Preserve the supplied license and NuGet metadata when redistributing.
