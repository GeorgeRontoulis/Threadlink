# Threadlink Sentinel

Accounts and platform capabilities routed to the installed provider, with a local profile from the start; per-account saves declared with `[Save]` that are transactional, versioned, migratable and recoverable. Achievements, statistics, leaderboards and products are platform-agnostic IDs that each platform authors and resolves itself.

Open **Threadlink ▸ Workspace** for the Hub, the Runtime monitor and project validation. Documentation: https://threadforge.gitbook.io/threadlink-documentation/
