# Threadlink Dextra

Per-player input with saved rebinding, prompts and claims; layered screens from prefabs or UI Toolkit documents that block gameplay input while open; interaction with `Interactable` and `InteractionSensor`. Screen sounds when Aura is installed; uGUI screens when uGUI is installed.

Open **Threadlink ▸ Workspace** for the Hub, the Runtime monitor and project validation. Documentation: https://threadforge.gitbook.io/threadlink-documentation/
