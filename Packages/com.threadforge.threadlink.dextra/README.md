# Threadlink Dextra

Per-player input with saved rebinding, prompts with designer-authored glyphs (`InputGlyphs`, `InputPrompt`) and claims; layered screens from prefabs or UI Toolkit documents that block gameplay input while open and go back with the Back action; interaction with `Interactable` and `InteractionSensor`. Screen sounds when Aura is installed; uGUI screens and prompts when uGUI is installed.

Open **Threadlink ▸ Workspace** for the Hub, the Runtime monitor and project validation. Documentation: https://threadforge.gitbook.io/threadlink-documentation/
