# Threadlink Showcase

Open `Scenes/Showcase.unity` and enter Play mode. Select a demo on the left; its controls, the packages it uses and a live log appear on the right. Each demo's code is one file under `Runtime/Demos` in the Threadlink Showcase package.

Importing the sample sets up Unity Localization for its English string table, `Localization/Threadlink Showcase` (**Threadlink ▸ Workspace ▸ Localization ▸ Set up** does the same). Add languages to that table to translate the demos' text.
