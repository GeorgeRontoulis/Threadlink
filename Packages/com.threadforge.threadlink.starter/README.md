# Threadlink Starter

A small complete game on Threadlink. Import the **Starter** sample, run **Threadlink ▸ Starter ▸ Add Starter Scenes To Build Profile**, open `Starter Bootstrap` and enter Play mode.

The game flow is one subsystem, `StarterGame`. Designers edit `Configuration/StarterContent` (screens, sounds, first level, slots, autosave interval). Documentation: https://threadforge.gitbook.io/threadlink-documentation/getting-started/starter
