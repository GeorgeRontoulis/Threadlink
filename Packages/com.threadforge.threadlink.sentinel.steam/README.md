# Threadlink Sentinel Steam

Steam for Sentinel through Unity's Steamworks package or Steamworks.NET. Enable it in Project Settings ▸ Threadlink ▸ Steam, where the game's Steam achievements, statistics, leaderboards and DLC are authored; they generate the IDs game code uses. Steam is off by default, so tests and the Editor never touch Steam unless enabled.

Open **Threadlink ▸ Workspace** for the Hub, the Runtime monitor and project validation. Documentation: https://threadforge.gitbook.io/threadlink-documentation/
